# IDN Gacha

The IDNPLAY Collectibles Mystery Pack reveal page. A visitor taps the pack, it tears open, and a card reveals their prize category. The whole site is one file: `index.html`.

Live at: https://mummyz.github.io/idngacha/

## How to update the site

1. Edit `index.html`.
2. Commit the change.
3. Push to `main`.

The live site refreshes in about a minute.

## Pack odds

One card per pack, drawn from a pool of 1,600 cards.

| Category  | Cards | Chance |
|-----------|------:|-------:|
| Advance   | 1,000 | 62.5%  |
| Elite     |   300 | 18.75% |
| Legendary |   200 | 12.5%  |
| Ultimate  |   100 | 6.25%  |

## Staff test

Long-press the logo for 1.5 seconds. A menu opens where you choose what the next pack reveals. It goes back to random after one pack.
